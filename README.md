# Vivek Gautam — Portfolio

A responsive personal portfolio for Vivek Gautam, showcasing his work and experience in cybersecurity, security research, and full-stack development.

## Website

- Intro and career highlights
- About section with technical skills
- Selected projects: Aegis, Soulbottherapy, and Smart-Health
- Experience, education, security research, and certifications
- Contact links and downloadable résumé
- Responsive layout with scroll-reveal and typewriter animations

## Built with

- HTML
- CSS
- Vanilla JavaScript

## Run locally

Open `index.html` in a web browser. No build step or package installation is required.

## Project files

- `index.html` — portfolio content and page structure
- `styles.css` — layout, styling, responsive design, and animations
- `script.js` — navigation and scroll-triggered text animations
- `Vivek Gautam Resume.pdf` — downloadable résumé
